# Offline Black Calendar

A minimal **Flutter** Android calendar app.

## Requirements

- Pure black app background.
- Offline runtime with no network feature.
- Minimal month view with previous/next navigation and day selection.
- Android APK output from GitHub Actions.
- No HTML/WebView UI.

## Build

The GitHub Actions workflow generates the Android platform files, runs analysis and tests, verifies the release manifest, and builds the release APK.
